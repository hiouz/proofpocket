# Three-minute demo outline

## 0:00–0:25 — Problem

An x402 or MPP payment can be valid at the protocol layer and still be something the user never intended to buy. ProofPocket places a human-governed, memory-aware boundary before signing.

## 0:25–1:25 — Three-act learning proof

1. Run Act 01. The unknown merchant requires review.
2. Approve the delivered outcome and show its Walrus Mainnet evidence.
3. Run Act 02. The same merchant receives a bounded automatic approval.
4. Run Act 03. The duplicate retry is blocked despite positive history.

## 1:25–2:15 — Real payment

1. Probe `/api/mpp/resource` and show the 402 challenge.
2. Pay 0.01 USDC through the Sui-MPP client.
3. Retry with the payment credential.
4. Show the paid resource and receipt.

## 2:15–2:45 — Independent witness

Paste the resulting digest into Settlement Witness. Show the Tatum Mainnet checkpoint and successful effects. Open the explorer link.

## 2:45–3:00 — Close

Walrus remembers what happened. Policy decides what is allowed. MPP moves value. Tatum proves it settled. ProofPocket gives agents autonomy without surrendering intent.
